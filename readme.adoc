== Pitfalls and Motivations

Shaders needs Tools.

You're building something 5 years ahead of industry standard?

- GPU-native (not simulating)
- Functional (not rasterization)
- Clean (not spaghetti)
- Efficient (no draw-call overhead)

The Pitfalls:

- Deep recursion → stack overflow
- Complex shaders → GPU performance issues
- Frequent layout changes → performance degradation
- Overuse of `std::any` → type safety loss
- Large uniform blocks → GPU upload overhead
- developer feedback missing
- runtime errors in shaders → shader debugging tools needed
- 3D scene complexity → frustum culling, LOD needed
- Cross-platform shader compatibility → abstraction layer needed
